# 09: BOM 版本与审核锁定

**What to build:** 工艺工程师可以创建并维护 BOM、提交审核，审核通过后的 BOM 才能被生产订单使用并被订单锁定版本。

**Blocked by:** 07, 08

**Status:** done

- [x] BOM 创建/编辑/子项维护（用量、损耗率）/查询可用
- [x] 同一产品可维护多个 BOM 版本，版本号唯一
- [x] BOM 需审核通过才可用于生产订单（订单创建时拒绝未审核 BOM 由 #11 落地）
- [x] 生产订单创建时锁定 BOM 版本，后续改 BOM 不影响既有订单（订单引用 BOM 版本由 #11 落地）
- [x] ProductSeeder 生成 3 个产品对应的 BOM 及子项，含已审核与未审核版本
