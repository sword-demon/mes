# 20: 库存出入库与流水

**What to build:** 仓库管理员可以查询并变更库存，每一次变更都留下流水且账实一致。

**Blocked by:** 03, 04, 08

**Status:** ready-for-agent

- [ ] 库存查询可用，按仓库、库位、物料、批次过滤，展示当前/可用/冻结数量
- [ ] 入库、出库、库存调整均通过 API 可用，并在事务中完成
- [ ] 每次库存变化都生成流水记录（变动前后数量、业务类型、关联单据）
- [ ] 出库数量超过可用库存时拒绝
- [ ] MaterialSeeder 生成仓库、库位、库存与流水，且流水净额等于库存当前值
