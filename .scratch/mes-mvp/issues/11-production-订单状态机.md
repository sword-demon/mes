# 11: 生产订单状态机

**What to build:** 生产经理可以创建生产订单并走完 草稿→待审核→已审核→已下达→生产中→已完成→已关闭 的全流程，也能暂停与取消。

**Blocked by:** 03, 09, 10

**Status:** ready-for-agent

- [ ] 订单创建/编辑/查询可用，计划数量、产线、计划时间、产品、BOM 版本、工艺路线版本均可指定
- [ ] 创建订单时校验收货 BOM 已审核且启用，未审核或停用的 BOM 被拒绝
- [ ] 创建订单时校验工艺路线已审核且启用（复用 `ProcessRoute::usable()`），未审核或停用的路线被拒绝
- [ ] 状态机只允许合法转移：草稿→待审核→已审核→已下达→生产中→已完成→已关闭，另有已暂停与已取消
- [ ] 审核、下达、暂停、取消、完成、关闭各自有独立接口，非法转移返回明确错误
- [ ] 创建订单时写入 BOM 与工艺路线版本快照，后续变更不影响既有订单；已下达后同样不可变更
- [ ] 前端订单列表支持按状态、产品、产线、日期筛选，订单表单可用
