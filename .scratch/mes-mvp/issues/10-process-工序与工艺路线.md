# 10: 工序与工艺路线

**What to build:** 工艺工程师可以配置工序与工艺路线并审核，生产订单能锁定路线版本，工序顺序成为后续流转的强制依据。

**Blocked by:** 07

**Status:** ready-for-agent

- [ ] 工序新增/编辑/停用/查询可用，含类型、标准工时、是否需检验
- [ ] 工艺路线创建、关联产品、添加工序并设置顺序与标准工时可用
- [ ] 一个产品可维护多条路线，路线需审核通过才能用于生产订单
- [ ] 生产订单创建时锁定工艺路线版本
- [ ] ProcessSeeder 生成 8 个工序与 3 条路线及路线工序，含已审核与未审核
