# 06: 基础数据：工厂车间产线人员

**What to build:** 基础数据管理员可以维护工厂、车间、产线、班组与人员，并预置一套模拟工厂组织数据。

**Blocked by:** 03, 04

**Status:** ready-for-agent

- [ ] 工厂/车间/产线/班组/员工的新增、编辑、停用、查询通过 API 可用，支持按父级过滤
- [ ] 编码唯一：重复编码返回明确错误信息
- [ ] 已产生业务记录的基础数据只能停用不能物理删除，停用数据不出现在新业务下拉中
- [ ] OrganizationSeeder 生成 1 工厂 / 2 车间 / 3 产线 / 若干班组 / 10 员工，且 Seeder 幂等
- [ ] 前端基础数据页面可用（列表、表单、停用操作）
