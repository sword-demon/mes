## Comments

- SN 详情的 404 用手动范围查询实现（路由键是 `sn` 而非 `id`，`whereKey` 会错比对主键，已有注释）；SN 的 label 端点仍返回 403（有 print 权限门槛，探测面与 show 不完全一致，风险低，记录为已知取舍）。
- SN 生成日志的 objectType 按 02 文档修订为「产品 SN 批次」——objectId 指向批次表主键，沿用「产品 SN」会在按对象回链时错链。
- 审查发现并修复 **Guard 缓存跨请求泄漏**：测试环境中框架会复用已解析的 Controller 实例（dump 两次请求 guard 对象 ID 相同），Guard 原来的「首次解析」缓存会让第二个用户的请求沿用第一个用户的范围。生产 FPM 每请求独立 app 不受影响，但 Octane 等常驻进程会遇到同类问题；缓存已改为按 user id 失效。
- 异常的归属校验统一为「订单产线优先」（与列表口径一致）；report 的 D1 双层校验（FormRequest required_without + Service）消息文案已统一。
