# 17: AI 任务记录与端到端验证

**What to build:** 建立 AI 任务记录，状态从待执行到执行中再到成功或失败；用一个不调用模型的任务跑通派发、执行、结果落库全链路。

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] AI 任务记录包含链路标识、任务类型、状态、发起人、模型标识、输入输出、错误、token 用量、耗时、起止时间
- [ ] 任务派发前创建待执行记录
- [ ] 任务开始执行时更新为执行中
- [ ] 执行结束写入成功或失败、输出、耗时
- [ ] 重试复用同一条记录，不新建
- [ ] 示例任务端到端成功，结果可查询
- [ ] 失败任务记录错误信息且状态为失败
- [ ] 有测试覆盖状态流转与失败路径
