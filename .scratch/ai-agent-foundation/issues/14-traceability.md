# 14: 追溯

**What to build:** 正向追溯的范围外 SN 返回 404；反向追溯结果不含范围外订单、批次与 SN；接口契约与数据粒度字段保持不变。

**Blocked by:** 04, 07, 08, 10

**Status:** done

- [x] 正向追溯先校验 SN 归属，范围外返回 404
- [x] 正向追溯返回的工序、检验、不良品、物料全部来自该 SN 所属订单
- [x] 反向追溯对库存流水、领料单、订单、批次、SN 逐层过滤
- [x] 反向追溯结果为空时返回 404，不返回带总数的空结构
- [x] `data_granularity` 字段与现有取值保持不变
- [x] 现有追溯测试通过

## Comments

- 正向追溯复用 SN 详情接口的收窄方式：`inDataScope` + 按 `sn` 手查 + 同文案 404，范围外 SN 与不存在不可区分；通过后服务内既有的订单/批次键查询保证各行归属不变。
- 反向追溯在库存流水（仓库所属工厂）与领料单（订单所属产线）两层显式过滤；订单、批次由过滤后的领料单派生，SN 关系用 `inDataScope` 兜底，脏数据不会跨范围漏出。
- 空结果统一由服务层抛 404 `物料批次不存在`；`data_granularity`、`has_data` 等契约字段未改动，既有空结构用例改为断言 404。
