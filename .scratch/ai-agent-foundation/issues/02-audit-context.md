# 02: 审计上下文与日志字段扩展

**What to build:** 操作日志增加「来源」与「链路标识」两个维度；人工请求默认记为人工，系统进程可记为系统，AI 执行入口可记为 AI；日志列表能按来源与链路标识筛选。

**Blocked by:** None (can start immediately)

**Status:** done

- [x] 操作日志新增来源字段，取值为人工 / AI / 系统，历史记录默认为人工
- [x] 操作日志新增链路标识字段，可空，带索引
- [x] 提供请求级或进程级的审计上下文，可设置来源、操作人、IP、链路标识
- [x] 日志写入优先读取上下文，上下文未设置时回退到 HTTP 请求
- [x] 日志列表支持按对象类型、来源、链路标识、关键字筛选
- [x] 日志选项接口返回来源可选值
- [x] 业务事务回滚时不产生日志
- [x] 密码、Token、密钥等敏感字段不出现在日志快照与摘要中
- [x] 现有审计日志测试通过
