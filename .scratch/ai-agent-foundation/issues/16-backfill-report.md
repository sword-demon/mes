# 16: 回填与上线检查

**What to build:** 一条命令把现有用户与仓库绑定到默认工厂；一条命令列出未配置数据范围的用户、产线范围但没有绑定产线的用户、未绑定工厂的仓库。

**Blocked by:** 01, 10

**Status:** done

- [x] 回填命令可重复执行且幂等，不会重复插入产线关联
- [x] 产线范围用户先绑定该工厂下全部产线
- [x] 所有用户与仓库绑定到第一个启用工厂
- [x] 报告命令输出三类未配置清单，带账号或仓库编码
- [x] 无工厂数据时报告命令给出明确提示，不静默成功
- [x] 两个命令均有测试覆盖

## Comments

- 回填只补 `factory_id IS NULL` 的用户与仓库，保留管理员已分配到其他工厂的数据；重跑不会把已收窄的产线加回来，只处理当前没有任何产线的 `line` 用户。
- 报告在存在启用工厂但发现未配置项时返回成功并打印清单；完全没有启用工厂时返回失败，避免上线检查被静默跳过。
