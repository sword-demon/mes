# 01: 用户归属与数据范围解析

**What to build:** 管理员可以在用户管理中设置账号所属工厂与负责产线；后端能把任意用户解析为「全部 / 本工厂 / 本产线 / 无权限」四种范围之一；`/me` 返回的数据范围字段保持原样，现有前端不受影响。

**Blocked by:** None (can start immediately)

**Status:** done

- [x] 用户新增与编辑接口可写入所属工厂与多个负责产线
- [x] 超级管理员与持有全部范围权限的用户解析为「全部」
- [x] 工厂范围用户解析为「本工厂」并带出工厂标识
- [x] 产线范围用户解析为「本产线」并带出产线标识列表
- [x] 无范围权限、工厂为空、产线为空三种情况一律解析为「无权限」
- [x] `/me` 的 `data_scope` 字段值与改造前完全一致
- [x] 现有全部测试通过
